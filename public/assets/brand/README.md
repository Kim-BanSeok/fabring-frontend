# 패브링 브랜드 자원

- `fabring-mark.svg`: 사용자가 선택한 로고 방향 02. 연결된 두 원단 조각과 흰색 대각 채널을 그대로 유지한 투명 SVG. 사이트의 한글 패브링 글자는 기존 Noto Sans KR로 표시한다.
- `fabric-hero.webp`: 승인한 코발트/데님 미리보기의 생성 소재 사진을 WebP 품질85로 인코딩한 소개 이미지. 실제 판매 원단으로 표시하지 않는다.
- `fabric-swatches.webp`: 같은 미리보기의 생성 소재 사진 모음. 데님·캔버스·거즈·린넨 시연 항목에만 사용하며 예시 표시를 유지한다.

실제 API 상품은 서버의 등록 사진만 표시한다. 등록 사진이 없거나 불러오지 못한 경우 위 사진으로 대체하지 않는다. Noto Sans KR 라이선스는 기존 `../fonts/OFL.txt`를 따른다.
