# React 전환 전 UX/UI 최종 검토 — 2026-10-11

구매자·판매자·관리자의 핵심 흐름을 실제로 눌러 문제를 재현한 뒤, HTML의 핵심 수정과 Figma 기준 반영을 완료했습니다. 현재 수정본을 React 전환의 기준으로 사용할 수 있습니다. React 런타임 전환이나 실제 API 연결은 이번 작업에 포함하지 않았습니다.

## 검토 후 수정한 부분

| 영역 | 확인한 문제 | 수정 결과 |
| --- | --- | --- |
| 모바일 메뉴 | 구매자·판매자의 뒤쪽 메뉴가 숨고, 관리자는 승인 메뉴와 로그아웃을 찾기 어려움 | 구매자·판매자 3열×2행, 관리자 2열×2행. 로그아웃 표시. 최소 44px 터치 영역 |
| 미리보기 도구·알림 | 고정 도구가 비밀번호 입력을 가림. 이전 화면의 성공 알림이 다음 화면에도 남음 | 도구를 문서 하단에 배치. 알림은 결과 화면을 떠나면 제거하고 클릭을 가로채지 않음 |
| 로그인 | 모바일 소개 영역이 커서 로그인 버튼이 첫 화면 아래에 있음 | 390×844 로그인 버튼 하단: 구매자 910→590px, 판매자 954→624px, 관리자 886→590px. 데스크톱 유지 |
| 로그인 뒤로가기 | 완료·오류 뒤 뒤로가기를 누르면 종료된 처리 화면에서 멈춤 | 처리 결과가 처리 중 이력을 대체. 직접 진입·새로고침에는 복구 버튼 |
| 구매자 입력과 검색 | 상세 확인 후 돌아오면 수량·일시·메모·문의가 지워지고 검색 조건도 풀림 | 같은 탭의 초안 보존, 성공·명시적 취소 시 정리. 검색 목록 복귀 조건 유지 |
| 재고·활용 안내 | 0마인데 거래 가능 표시와 요청 폼이 남음. 활용 예시가 제작 가능 판정처럼 보임 | 요청 가능 상태를 먼저 안내하고 기존 예약·다른 원단으로 이동. 활용 아이디어 문구로 정정 |
| 부자재 | 같은 판매처 링크 반복. 모바일 선택 결과가 화면 아래에 숨고 도안 복귀 경로 없음 | 지도·목록과 선택 상세로 정리. 선택 카드에 초점 이동. 원래 도안으로 돌아가기 |
| 판매자 입력 | 직접 입력 왕복 시 유실. 사진 선택 후 보완 저장·재편집에 과거 값 표시 | 입력 초안을 보존하고 저장 후에는 최신 원단 정보로 재편집 |
| 판매자 사진·예약 | 사진 영역이 과도하게 길고 종료 예약에도 처리 전 안내 표시 | 모바일 사진 행을 압축해 폼 높이 2833→2165px. 5개 예약 상태에 맞는 안내·수량 라벨 |
| 관리자 검토 | 모바일 원단 목록이 상세를 밀어냄. 거절 사유를 쓰다가 재확인하면 소실 | 모바일 원단 선택창, 중복 안내 제거, 원단별 거절 사유 초안 보존 |

사용자 입력 초안은 API 객체별 메모리 Map으로 일반 흐름과 상태 예시를 분리합니다. 영구 저장하지 않으며 새로고침으로 초기화됩니다. 로그아웃·예시 데이터 초기화 시 해당 초안을 비웁니다. 이미 제출한 예시 기록은 기존 localStorage 정책을 유지합니다.

## Figma 반영

[최신 작업 페이지](https://www.figma.com/design/uYO6eu041WwmEBKAfA7a6Y?node-id=122-12)의 관련 문구와 중복 UI를 수정했습니다.

- 부자재 지도와 판매처 상세의 중복 바로가기 숨김. 기존 지도 핀 3개·목록 이름 3개를 해당 상세로 연결해 이동 경로 유지.
- 활용 아이디어 문구·배지, 관리자 거절 사유 입력 유지 안내, 판매자 상태별 재고 제목 수정.
- 관리자 승인 검토 하단의 중복 안내 숨김.
- [반응형·동작 기준](https://www.figma.com/design/uYO6eu041WwmEBKAfA7a6Y?node-id=227-8029)을 편집 가능한 참고 프레임에 기록. 기존 Figma 화면은 데스크톱 기준이며, 모바일 화면을 새로 전부 제작한 것은 아닙니다. 모바일 변경은 HTML 실화면과 이 기준으로 확인합니다.

서비스 화면·상태 177개 및 보류 8개 범위는 유지합니다. 참고 프레임은 서비스 화면 수에 포함하지 않습니다. 원본 레이어 삭제 대신 숨김을 사용했고, 수정 전 속성과 변경 ID는 `figma-sync.json`에 보관했습니다. Figma의 예약 레코드는 기존 조건부 표시를 유지합니다.
