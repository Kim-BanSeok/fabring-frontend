# 원단 기반 도안 추천·도안 조회 API 연동

2026-10-12 · 계약 검토 기준 `7dc28c79994295daee635524d05048574247a6d9`

기존 원단 상세의 추천 카드, 판정 근거, 도안 부품 표와 픽업 요청 흐름을 실제 API22~24로 연결했습니다. [연결 현황의 M4](../../INTEGRATION_STATUS.md#core-work)에 해당합니다. 전체 테스트295개·lint·build와 실제 HTTP54항목·live adapter25항목, 브라우저 처리 후 읽기 전용 GET/DB23항목을 통과했습니다. 실제 React에서 추천→도안→권장 수량 요청→참고 도안이 저장된 상세→취소와 가격 변경 시 전송 차단을 확인했습니다. 아래 계약 검토 내용은 실행 통과 수에 포함하지 않습니다.

## 연결 계약

| API | 요청 | 응답과 처리 |
| --- | --- | --- |
| 22 도안 목록 | `GET /patterns` | 사용 중인 도안만, category·keyword·page·size 조건의 페이지 |
| 23 도안 상세 | `GET /patterns/{patternId}` | 도안명·설명·허용 소재/두께·검토 표기·부품별 가로/세로/장수 |
| 24 원단 기준 추천 | `GET /fabrics/{fabricId}/recommendations` | available·items·notices·message, 도안별 판정·근거·롤 필요/구매 길이·금액 |
| 25 예약 요청의 선택 도안 | `POST /reservations`의 `pattern_id` | 사용 중인 도안 번호를 참고 정보로 함께 저장 |

기본 주소는 `/api/v1`입니다. [명세22~24][api]는 공개 API이며 로그인 없이 조회할 수 있습니다. 로그인한 세션의 토큰을 함께 보냈을 때 잘못되거나 만료된 토큰이면401입니다. 예약25는 BUYER 인증이 필요합니다. 없는 원단·삭제 원단 또는 없거나 비활성인 도안은404입니다.

도안 목록은 도안 번호 오름차순입니다. 분류는 최대50자의 정확히 일치하는 값이고 검색어는 최대100자로 이름·별칭에서 찾습니다. page는0부터, size는 기본20·최대50입니다. 도안 상세 부품은 등록 순서입니다. 이 API는 실제 크기 출력 파일·시접 포함 여부·필요 부자재 목록을 제공하지 않습니다. 값이 없을 때 예시 파우치 치수·지퍼·실로 채우지 않습니다.

## 추천 판정과 표시의 경계

추천은 AI가 아니라 서버의 규칙 계산입니다. 부품 가로는 원단 폭 방향, 세로는 길이 방향이며 부품을 회전하거나 다른 배치를 탐색하지 않습니다.

| 항목 | 자투리 | 롤 |
| --- | --- | --- |
| 필요한 폭 | 모든 부품의 가로×장수 합 | 부품 가로의 최댓값 |
| 필요한 길이 | 부품 세로의 최댓값 | 모든 부품의 세로×장수 합 |
| 구매 단위 | 한 장 전체 | 필요 길이를90cm 단위로 올림 |
| 추천 금액 | API의 estimated_price는 null | 90cm당 원단 가격×마 수 |
| 정렬 | 필요한 부품 면적이 큰 도안부터 | 구매 마 수가 적은 도안부터 |

자투리 카드에 표시하는 전체 원단 가격은 현재 원단 상세의 가격이며 추천 API가 계산하거나 예약 당시 고정한 금액이 아닙니다. null을0원으로 바꾸지 않습니다. 롤 근거의 LENGTH.required는 올림 전 필요 길이가 아니라 구매 길이이며 actual은 남은 길이에서 확보 길이를 뺀 구매 가능 길이입니다.

- `SUITABLE`: 크기·소재·두께 조건 충족. 최대5개입니다.
- `NEEDS_CHECK`: 크기·두께는 맞지만 소재가 UNKNOWN입니다. 최대3개이며 소재 근거의 met은 null입니다. 적합으로 표시하거나 제작 가능하다고 확정하지 않습니다.
- `available: true`, 빈 items: 원단을 비교할 수 있지만 현재 반환된 추천이 없습니다.
- `available: false`, 빈 items: 게시 중이 아니거나, 자투리의 수락된 예약이 있거나, 롤의 구매 가능 길이가90cm 미만입니다. 결과 없음과 거래 불가를 구분합니다.

반환 개수 제한이 있으므로 특정 도안이 응답에 없다는 사실만으로 절대 제작할 수 없는 도안이라고 단정하지 않습니다. 항상 실물의 촉감·결 방향·수축 확인 안내를 유지합니다. 데이터 조회 실패를 빈 추천이나 부적합으로 바꾸지 않습니다.

## 픽업 요청과 도안 정보

선택한 도안은 숫자 pattern_id로 전달합니다. 예전 시연용 `/buyer/patterns/pouch`를 임의의 실제 도안 번호로 대체하지 않습니다. 예약 서버는 도안의 존재·활성 여부를 검사하지만 도안과 원단의 적합성이나 권장 길이를 다시 계산하지 않습니다. 화면의 제작 조건 확인과 서버의 예약 가능 재고 검사를 구분합니다.

도안 연결 요청은 진입 시 도안·추천을 확인하고 전송 직전에 원단·도안·추천을 다시 조회합니다. 추천이 적합에서 바뀌거나 필요한 길이보다 적게 요청하면 전송하지 않습니다. 원단 가격·판매 방식 변경도 이전 금액으로 자동 요청하지 않고 재확인을 안내합니다. 도안별 수량 초안은 분리하여 이전 도안의 적은 수량을 새 권장 수량으로 오인하지 않습니다. 도안 연결 없는 일반 요청에서는 pattern_id를 null로 보냅니다. 소재 확인 필요일 때는 적합성을 확정하거나 연결되지 않은 문의 전송을 성공 처리하지 않습니다.

원단 가격·재고·도안 조건은 조회 이후 달라질 수 있습니다. 추천 화면의 금액은 예상값이고 실제 롤 예약 금액은 예약 응답 및 상세의 estimated_price를 사용합니다. 자투리 예약 금액·당시 원단 스냅샷의 계약 공백은 [B1](../../API_FOLLOWUPS.md#b1-예약-이력에-표시할-원단-정보와-금액)에 남습니다.

여러 조회와 예약 생성은 한 트랜잭션이 아니므로 전송 직전 확인 이후의 변경까지 원자적으로 막는 구조는 아닙니다. 추천 버전·예약 시 적합성 재검사가 필요해지면 서버 계약을 별도로 협의합니다.

테스트 전 로컬 DB에는 도안이0건이어서 기존 데이터를 변경하지 않고 활성4건·비활성1건의 가상 도안과 전용 원단·계정을 추가했습니다. 도안명과 검토 표기에 검증용 예시임을 표시했으며 검증된 제작 도안으로 주장하지 않습니다. 도안1의35×46cm1장과35×45cm1장은 필요 길이91cm, 구매 길이180cm(2마), 예상 금액6,400원입니다. 실제 서버에서 이 추천으로 요청→수락→수령을 처리하고900cm의 롤 잔량이720cm, 확보 길이가0cm가 된 것을 확인했습니다. 도안·부품 fixture 준비는 DB 작업이고 예약 처리 검증은 실제 HTTP이며 둘을 구분합니다.

브라우저 확인 후 읽기 전용 최종 확인에서도 기존11개 모델의 행 해시가 변경되지 않았습니다. 요청133은 CANCELED이며 도안1·180cm·6,400원이 보존됐습니다. 앞선 HTTP와 adapter의 수령 완료 예약도 그대로 유지됐습니다. 오류 모의 테스트를 실제 네트워크 장애 재현으로 세지 않으며 공개 증거에는 비밀번호·토큰·개인 연락처·DB 접속 정보를 포함하지 않습니다.

## 브라우저 확인

실제 구매자로 원단157의 추천에서 도안1을 선택하고 등록 부품을 확인했습니다.91cm가 필요한 도안은2마(180cm)가 기본값이며1마 입력은 차단됩니다.2마·6,400원 요청133을 생성한 뒤 예약 상세의 참고 도안과 실제 저장값을 확인하고 취소 내역으로 이동했습니다. 원단 목록 검색 맥락은 추천·도안·픽업 이동에서 보존합니다.

- 소재 UNKNOWN 원단145는 소재 확인 필요로 표시하고 추천 도안을 연결한 구매를 차단합니다. 해당 픽업 주소로 직접 들어가도 조건 확인 화면을 보여 줍니다. 일반 픽업과 도안 적합성 보장은 구분합니다.
- 원단146의 추천 없음과 원단151의 현재 추천 불가를 다르게 표시합니다. 비활성 도안5는 조회 오류를 표시하며 시연 파우치로 대체하지 않습니다.
- 도안 검색어 `파우치`로 목록→상세→목록을 이동해도 검색 조건이 유지됩니다. 임의 `ma=99`를 붙여도 실제 추천의2마가 적용됩니다.
- 픽업 폼을 연 뒤 전용 원단157의90cm당 가격을3,200원에서3,300원으로 바꾸었습니다. 전송 직전 차이를 감지해 새 예약을 보내지 않고 기존 메모·수량을 보존했습니다. 도안을 다시 확인하면6,600원이 표시되고 폼으로 돌아왔을 때 메모가 유지됐습니다. 확인 후 테스트 원단의 가격은3,200원으로 복원했습니다.
- 모바일390px 뷰포트에서 도안·픽업의 문서 폭과 스크롤 폭은 모두375px로 가로 넘침이 없었습니다. 픽업 페이지의 제목과 H1 포커스도 실제 로딩 완료 화면에 맞게 갱신됩니다.
- 마지막 브라우저 로그 조회의 오류·경고는0건이었습니다. 모바일 확인 후 뷰포트 재정의를 해제했습니다.

## 이번 범위 밖

판매자 AI 보조 등록 M5는 요구사항 P0의 별도 필수 작업입니다. 문의 작성·답변, 개인 프로필 수정, 관심 저장, 부자재 지도와 공장 목록의 대상 확인도 이번 추천 연결로 완료되지 않습니다. 등록 시간(FAB-13), 게시 후 비공개(ADMIN-02), AI 세션 보존 정책과 확정 약관 문안은 별도 확인 사항입니다.

현재 검증 환경은 로컬 PC입니다. 이 작업의 커밋·푸시는 팀원이 접속할 공용 서비스 배포가 아닙니다. 프론트·API·DB·업로드 이미지 저장소와 HTTPS/CORS·공용 계정 준비는 통합 마무리에 포함합니다.
