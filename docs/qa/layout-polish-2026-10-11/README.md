# 화면 배치 재검토 및 수정 · 2026-10-11

사용자 스크린샷의 관리자 로그아웃 아래 빈 영역을 재현하고, 기존 HTML과 같다는 기준 대신 실제 사용 화면의 정렬·여백·스크롤을 검토했습니다. React 기본 진입점에 반영했습니다. Figma 파일은 이번 작업에서 수정하지 않았습니다.

## 확인한 문제와 수정

| 구간 | 확인한 문제 | 수정 |
