# 관리자 본문 레이아웃 점검

2026-10-11, 현재 React 미리보기를 기준으로 확인했다. 화면 전체를 캡처했으며 사이드바·상단바·시연 도구까지 포함한다. `AdminPage.jsx`와 `prototype/pages/admin.css`만 수정했다. 공통 프레임·사이드바·시연 도구 및 빈 상태 높이는 root의 별도 공통 수정이다.

## 수정한 문제

- 작은 화면의 표에서 판매자·상태·상세 링크가 가로 스크롤 뒤에 숨었다. 900px 이하에서는 각 행을 라벨 있는 세로 구성으로 보여 준다. 상품 사진·제목·판매자·상태, 대시보드 신청일·상태, 판매자 상세 링크가 모두 표시된다.
- 승인 검토는 1024px에서 후보 목록 옆의 좁은 패널에 사진과 정보가 세로로 쌓였다. 1250px 이하에서는 후보 선택을 드롭다운으로 옮겨 본문 폭을 확보한다. 1024px에서 전체 페이지 높이가 1363px에서 1175px로 줄었다. 이 수치는 공통 프레임 조정도 포함한다.
- 1151px 경계에서 정보 값 폭이 63px까지 줄어 치수가 네 줄로 갈라졌다. 드롭다운 기준 보완 후 값 폭은 347px이며 각 항목이 한 줄에 표시된다. 1200px도 확인했다.
- 900px 이하의 승인 사진은 검토 패널 폭을 채우고 높이는 200px로 맞췄다. 휴대폰 검토 명세는 라벨과 값을 나란히 표시한다. 관리자 제목은 한국어 단어 중간의 불필요한 줄바꿈을 줄였다.

## 검증

- 11개 화면: 대시보드, 판매자 목록·상세, 상품 목록·상세, 승인 목록·확정·거절·결과, 상태 선택, 오류 복구.
- 1440×900, 1366×600, 1024×768, 390×844 각각 위·중간·아래: 수정 전후 각 132개 캡처. `before-metrics.json`, `after-metrics.json`에 전체 화면 좌표를 기록했다.
- 추가 경계폭 1151/1200/768px은 `before-edges.json`, `after-edges.json`과 `*-edge-*.png`로 확인했다. 768px 상품 표의 내부 가로 폭은 680px에서 실제 패널 폭 452px로 맞아졌다.
- 판매 완료·거절 판매자·거절 원단의 빈 목록 3종×4크기는 `empty-verification.json`에 기록했다. 빈 상태 높이는 120~188px, 가로 넘침과 실행 오류는 없다.
- `verification.json`: 표/열 머리글 접근성, 모든 셀의 data-label과 화면 폭 내 표시, 모바일 상품 승인과 판매자 승인 클릭, 1024px 원단 선택 및 사진·정보 같은 행 배치 통과. `AdminPage.jsx` oxlint 경고·오류 0개.

시각 확인용 대표 파일: `after-fabrics-390x844-middle.png`, `after-dashboard-390x844-middle.png`, `after-approvals-1024x768-middle.png`, `after-edge-approvals-1151.png`, `after-edge-fabrics-768.png`, `after-soldout-1440x900-top.png`.

실제 서버 연결 없이 예시 데이터로 검사했다. 표의 접근성 트리와 네이티브 역할은 확인했지만 별도 스크린리더 사용자 시험을 수행한 것은 아니다.
