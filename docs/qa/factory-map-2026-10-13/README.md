# 공장 목록과 네이버 지도 검증

## 키 설정 후 실제 지도 확인

로컬 개발 PostgreSQL과 실제 HTTP API, 네이버 Geocoding 및 Maps SDK로 확인했습니다. 네트워크 응답이나 지도 SDK를 대체하지 않았습니다.

- 후보 28곳 모두 원문 주소와 맞는 좌표를 DB에 저장했습니다. 고유 주소와 지도 마커는 26개입니다.
- `(주)오선`의 원문 `봉암리 44-0`과 네이버 `봉암리 44`는 부번 0의 생략으로 처리하며, 다른 지번은 허용하지 않습니다. 원문 주소는 유지합니다.
- SDK 콜백이 전역 공개보다 먼저 실행되는 순서를 처리해 실제 SDK에서 지도를 생성합니다.
- 최초 진입에서 전체 마커와 아이콘이 보이도록 범위와 여백을 조정했습니다. 업체를 명시적으로 선택할 때 해당 마커로 이동합니다.
- 데스크톱 1440px·모바일 390px에서 실제 지도 타일, 26개 마커, DB 좌표 28곳의 일치, 목록→마커·마커→목록 선택, 상세·복귀를 확인했습니다.
- 브라우저 오류와 가로 넘침은 없었습니다.
- 프론트 지도 전용 테스트 7개와 빌드가 통과했습니다. lint에 신규 경고는 없으며 기존 판매자 음성 컴포넌트 경고 5개가 남습니다.
- 백엔드 전체 테스트 514개와 lint가 통과했습니다. 같은 주소의 좌표가 이미 저장되면 재호출하지 않으며, 현재 남은 주소는 0개입니다.

최신 결과는 [naver-live/checks.json](naver-live/checks.json), 화면은 [데스크톱](naver-live/desktop.png)·[모바일](naver-live/mobile.png)입니다. 좌표 없는 초기 상태의 검증 기록은 아래에 보존합니다.

## 저장된 시연 세션에서 일반 주소 재진입

사용자 브라우저의 `/buyer/supplies`가 저장된 시연 모드를 이어받아 예시 판매처 3곳을 표시하는 문제를 실제 탭에서 확인했습니다. 이전 실제 지도 검증은 `mode=live`와 로그인 상태에서 수행해 이 경우를 포함하지 못했습니다.

- 일반 공장 지도·상세 주소는 실제 조회를 기본으로 사용합니다. 기존 공개 공장 API를 사용하므로 로그인 전에도 표시합니다.
- 명시적인 `mode=demo`와 Figma 상태 예시는 유지하며, 예시 지도 내부 링크는 시연 모드를 명시합니다.
- 로그인한 판매자·관리자도 공개 지도를 볼 수 있으며 실제 계정 역할은 유지합니다. 개인 정보·예약 등 기존 역할 검사와 로그인 요구는 유지합니다.
- 현재 사용자 탭을 같은 주소로 새로고침해 로그인 없이 후보 28곳·위치 확인 28곳·네이버 마커 26개가 표시되는 것을 확인했습니다. [사용자 탭 화면](naver-live/public-default-iab.jpg).
- 모드·역할·라우팅과 공장 전용 테스트 28개, 빌드가 통과했습니다. lint 오류와 신규 경고는 없습니다.

## 마커 선택 이동·확대

- 선택 쿼리 변경이 전체 화면을 다시 마운트해 지도가 깜빡이던 문제를 수정했습니다. 실제 지도 목록에서는 세션과 페이지가 바뀔 때만 마운트가 바뀝니다.
- 마커·목록 선택은 기존 지도에서 선택 좌표로 이동하면서 최소 줌 16까지 확대합니다. 사용자가 이미 더 확대했다면 그 배율을 유지합니다.
- `전체 위치` 버튼은 모든 공장의 범위로 돌아갑니다. 그 뒤 동일한 마커를 재선택해도 다시 확대합니다.
- 실제 사용자 브라우저에서 우진화스나(주) 마커 선택, 축척 5km→100m, 전체 위치 복귀 100m→5km, 같은 마커 재선택 5km→100m를 확인했습니다. 지도 컨테이너와 지도 컨트롤의 접근성 노드가 유지되었으며 마커 26개는 유지됩니다.
- 지도 이동·배율, 마운트 유지, 모드·권한·라우팅 관련 테스트 30개와 빌드가 통과했습니다. lint 오류와 신규 경고는 없습니다.
- [전체 위치 화면](naver-live/marker-overview-iab.jpg), [마커 선택 후 확대 화면](naver-live/marker-focus-iab.jpg), [동작 확인 기록](naver-live/marker-interaction-checks.json).

## 이동 시간 단축 (이전 설정)

- 마커 선택은 `panTo`로 180ms 이동한 뒤 `updateBy`로 좌표·배율을 즉시 적용합니다. `morph`는 배율이 바뀌면 duration을 적용하지 않아 사용하지 않습니다. [공식 지도 이동 API](https://navermaps.github.io/maps.js.ncp/docs/naver.maps.Map.html#panTo).
- `전체 위치`는 `fitBounds`로 즉시 복귀하고, 타일 페이드 시간은 100ms로 줄였습니다. 네트워크에서 이미지를 받는 시간은 별도입니다.
- 새 선택·전체 복귀·지도 제거 시 이전 이동을 중단합니다. 늦게 실행된 이전 완료 콜백은 최신 위치를 덮어쓰지 않습니다.
- 실제 사용자 탭에서 전체 복귀 5km, 마커 재선택 100m, 연속 마커 선택·전체 복귀를 확인했습니다. 마커 26개는 유지됩니다.
- 관련 테스트 32개와 빌드가 통과했으며 lint 오류와 신규 경고는 없습니다. [속도 설정·검증 기록](naver-live/marker-speed-checks.json), [화면](naver-live/marker-speed-iab.jpg).

## 짧고 부드러운 이동 (현재 설정)

- 네이버 공식 GL 서브모듈을 사용해 이동과 확대·축소가 한 전환에서 이어지게 했습니다. 마커 선택과 `전체 위치` 모두 300ms, `easeOutCubic`으로 끝부분에서 감속합니다. [공식 GL 안내](https://navermaps.github.io/maps.js.ncp/docs/tutorial-1-GL.html).
- 벡터 지도 상세 배율은 15로 기존 이미지 지도 16과 같은 수준입니다. 더 확대한 배율은 유지하며, WebGL을 사용할 수 없는 환경에서는 SDK의 이미지 지도 대체 동작을 사용합니다. 부드러운 실수 배율 전환은 GL 환경에서 적용됩니다.
- 기본 SDK의 load 대신 GL 모듈 완료 콜백을 기다리고, 지도 `init` 이후 처음 범위와 선택 확대를 적용해 초기 카메라에 선택 위치가 덮이는 문제를 막았습니다.
- 새 동작 전에 이전 전환을 중단합니다. 타일 페이드는 120ms이며, 지도 자료를 받는 네트워크 시간은 전환 설정과 별도입니다.
- 실제 사용자 탭에서 GL 캔버스, 후보 28곳·마커 26개, 선택 주소 재진입 100m, 전체 복귀 5km, 같은 마커 재선택 100m, 전체 보기 직후 다른 공장 선택을 확인했습니다.
- 관련 테스트 32개와 빌드가 통과했으며 lint 오류와 신규 경고는 없습니다. [현재 설정·검증 기록](naver-live/marker-smooth-checks.json), [선택 확대 화면](naver-live/marker-smooth-iab.jpg).

## 키 설정 전 목록·대체 화면 확인

양주시청 2026년 9월말 원본을 적재한 별도 로컬 PostgreSQL과 실제 HTTP API로 검증했습니다. 네트워크 응답을 대체하지 않았습니다.

- 공장 전체 2,919개, 부자재 후보 28곳, 주소 26개.
- 실제 모드 `/buyer/supplies`에서 후보 28곳의 이름·생산품·주소를 조회.
- 목록 선택, 업체 상세, 선택 업체를 유지한 목록 복귀 확인.
- 데스크톱 1440px, 모바일 390px에서 가로 넘침과 브라우저 오류 없음.
- 지도 키 미설정 시 업체 목록과 안내가 유지되고 SDK 외부 호출이 발생하지 않음.
- 이 검증 당시 좌표는 모두 null이었으며 네이버 외부 호출은 수행하지 않았습니다.

`checks.json`은 실제 브라우저 확인 결과이고 `desktop.png`, `mobile.png`는 그 상태의 화면입니다.

신규 공장 API·SDK 테스트 6개는 통과했습니다. 전체 프론트 테스트는 384개 중 382개 통과하고, 최신 main 원본에서도 같은 자투리 길이 검증 관련 2개가 실패합니다. 지도 기능으로 추가된 테스트 실패는 없습니다. lint에 신규 경고는 없으며 기존 판매자 음성 컴포넌트의 경고 5개가 남습니다.

백엔드 [배포·적재 가이드](../../../../backend-local/docs/factories/DEPLOYMENT.md)에 공용 환경 재현 명령과 네이버 설정을 기록했습니다.
